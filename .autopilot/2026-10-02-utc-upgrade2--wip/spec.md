# Спецификация: доработка по TZ.docx (2026-10-02)

## Задача

Пользователь дал файл TZ.docx с 5 пунктами правок: (1) добавить нумерацию «4. » к вопросу про категории объектов в форме создания УТК, (2) обновить значения «Категории объектов» в трёх примерах записей в Справочной системе и в кнопке «Пример» формы, (3) сделать дерево УТК выразительнее (визуальные связи), (4) заменить экспорт реестра из CSV на HTML, (5) добавить скачивание карточки записи в .html из просмотра.

## Решение

После доработки:
- В форме «+ Создать УТК» и в AI-мастере поле категорий называется «4. Назовите более общую группу Объектов…» (единый порядок с другими полями 1–8).
- В Справочной системе в «Примерах записей» у каждого из трёх примеров категории объектов — новые, короткие формулировки; кнопка «Пример» в 4-м вопросе формы подставляет такое же новое значение.
- Режим «Дерево» показывает иерархию явно: линии-ветви слева от узлов, отступ по уровням, листья без стрелок.
- Экспорт из реестра — кнопка «HTML» вместо «CSV» (JSON остаётся): скачивается `utc_records.html` с красивой таблицей записей по текущим фильтрам.
- В просмотре карточки УТК — кнопка «Скачать»: скачивается `.html` со всеми полями записи, структурировано и стилизовано.

## Решения по реализации

- **Нумерация поля 4 — одна константа.** `UTC_FIELD_LABELS.categories` в `lib/types.ts` получает префикс «4. »; от неё рендерится ручная форма. AI-мастер: той же правке подлежат `lib/wizard-prompts.ts` (системный промпт, пункт 4, и `questions.categories`). Почему: один источник правды для надписи.
- **Примеры.** Значения категорий в трёх примерах в `components/help-guidance.tsx` (массив `examples[].categories`) — новые, остальные поля не трогаем. Кнопка «Пример» в 4-м вопросе формы подставляет **одно** значение — «Исследуемые микроматериалы» (равно примеру 1 справки; так было и раньше — форма всегда подставляла один пример; остальные два примера в форме недоступны, это поведение «как и сейчас» из ТЗ). Источник — `UTC_EXAMPLES.categories` в `lib/types.ts`.
- **Дерево.** Только `components/utc-tree.tsx`: рекурсивный узел рисует вертикальную линию-«ветку» слева (CSS: border-l + псевдоэлементы, у последнего ребёнка — «└─»-излом). **Состав узла не меняется**: бейдж типа («Продукт» / «Ключевой элемент» / «Ключевой процесс») и «ID: …» остаются как сейчас, добавляется только выразительная связь (линии, отступы). У узла без детей стрелки-ветки нет. Линии продолжаются на каждом уровне рекурсивно. Отступ уровня сохраняется (level * 24px + линия). Никаких изменений данных/API. Почему: выразительность без перестройки модели.
- **Экспорт реестра.** В `app/api/utc/export/route.ts` ветка `format === 'csv'` заменяется на `format === 'html'`: рендер той же выборки `records` (те же фильтры) в валидный HTML-документ с inline-CSS (таблица, тёмный/светлый нейтральный стиль), `Content-Disposition: attachment; filename="utc_records.html"`, `Content-Type: text/html; charset=utf-8`. Формат `json` не трогаем. Клиент: `components/search-filters.tsx` — кнопка «CSV» → «HTML» (иконка FileCode или аналогичная, вызывает `onExport('html')`); `app/page.tsx` `handleExport` принимает `'json' | 'html'`, имя файла `utc_records.<format>`.
- **Скачивание карточки .html.** Новый роут `app/api/utc/[id]/export-html/route.ts`: GET, авторизация как в других роутах карточки (сессия обязательна; 401 без входа; 404 если записи нет; 403 если не автор и не админ — по аналогии с alt-applications/competitors, `record.canEdit`). Возвращает HTML-документ со всеми полями записи + даты, стилизованный (inline-CSS), `Content-Disposition: attachment; filename="utc-<id>.html"`. Клиент: `components/utc-view.tsx` — кнопка «Скачать» (иконка Download, в шапке карточки), GET на роут, blob → download.
- **Общий рендер HTML.** Для обоих экспортов — единая функция `renderUtcHtml(...)` в новом `lib/export-html.ts` (рендер списка и рендер карточки как два режима/две функции). Почему: один стиль, один шов, один источник разметки.
- **Оба .html открываются без интернета** (inline-CSS, без внешних ссылок/CDN) — чтобы файл был читаем в любом браузере и офлайн. Почему: экспорт — автономный артефакт.

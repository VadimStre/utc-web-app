# 09 — Доступ к поиску только авторам (R12)

**Требования:** R12
**Blocked by:** —
**Зона:** `components/utc-view.tsx`, `app/api/utc/[id]/alt-applications/route.ts`, `app/api/utc/[id]/competitors/route.ts`
**Волна:** 1
**Status:** ready

## Что должно заработать
Режимы «Поиск конкурентов-аналогов» и «Поиск альтернативных областей применения (новых рынков)» доступны только авторам данных УТК (по своим УТК). У администратора — полный доступ.

## Из брифа, дословно
> «Режимы «Поиск конкурентов-аналогов» и «Поиск альтернативных областей применения (новых рынков)» должны быть доступны только для тех пользователей, которые являются авторами данных УТК, т.е. по своим УТК. У администратора – полный доступ»

## Разделы спецификации
§12.

## Критерии приёмки
- [ ] В utc-view: «Альт. применения» (и «Конкуренты») видны только при `record.canEdit` (автор/админ)
- [ ] API alt-applications: проверка прав (isAdmin || ownerId === userId), иначе 403
- [ ] API competitors: аналогичная проверка прав в POST
- [ ] Не-автор на чужой записи не видит оба блока/получает 403 при прямом вызове API

## Примечания
- Системные записи (ownerId=null): по ТЗ «авторы данных УТК» — доступ только админу.

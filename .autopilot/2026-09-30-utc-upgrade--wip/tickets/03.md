## Критерии приёмки
- [ ] Кнопка «Скачать» в блоке результата (после поиска)
- [ ] Скачивается валидный `.docx` (открывается в Word/Google Docs)
- [ ] В файле есть: «8. Формулировка УТК» (значение из записи), «Новые области для той же Функции», «Новые типы Продуктов», «Сводный рейтинг всех вариантов»
- [ ] Скачивание работает с серверного API (не на клиенте)

## Примечания
- Использовать npm-пакет `docx` (генерация на сервере). Проверить, что он уже есть в `package.json`; если нет — добавить в dependencies.
- Не забыть про `Content-Disposition: attachment; filename="utc-alt-applications-<id>.docx"`.

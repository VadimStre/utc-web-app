## Критерии приёмки
- [ ] У конкурентов ссылки «Источник» видны (уже есть — проверить)
- [ ] У альтернативных применений под вариантами (по крайней мере рекомендованными) — ссылки «Источник» (внешние, открываются в новой вкладке)
- [ ] Поиск через Serper выполняется по описанию варианта, не ломает основной ответ (исключения обрабатываются)
- [ ] Лимит: ~5 поисков на запрос (рекомендованные), таймаут на каждый

## Примечания
- Расширить тип `AltApplicationVariant`: `sources?: { title: string; url: string }[]` (или `sourceUrls?: string[]`).
- В route после первого LLM-запроса — собрать ссылки для рекомендованных (топ по баллу) и прикрепить.

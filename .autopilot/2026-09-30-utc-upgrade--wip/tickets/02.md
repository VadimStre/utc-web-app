# 02 — Кнопка «назад» в AI-мастере (R02)

**Blocked by:** —

## Что должно заработать
В много-экранной форме «Создать УТК с помощью AI мастера» — кнопка «Назад», возвращающая к предыдущему вопросу (шаг-1), с сохранённым ответом.

## Из брифа, дословно
> «Сделать кнопку «назад» для перемещения по много-экранной форме «Создать УТК с помощью AI мастера»»

## Разделы спецификации
§2.

## Критерии приёмки
- [ ] В диалоге мастера рядом с «Отмена» есть «Назад» (на шаге 1 неактивна/скрыта)
- [ ] По нажатию — шаг уменьшается на 1, показывается предыдущий вопрос, в поле ответа — прежний ответ
- [ ] Серверный API корректно откатывает сессию (currentStep, messages)

## Примечания
- Сессии в памяти (`lib/wizard-sessions.ts`).
- Рекомендуется API `POST /api/utc/wizard/back` (тело: wizardSessionId), откатывает currentStep на 1 и удаляет последнюю пару сообщений (user+assistant).

# Спецификация — доработка системы УТК (2026-09-30)

Источник: манифест `manifest.md` (12 требований). Прогон autopilot, режим полуавтомат, глубина обычная.

## Термины
- **УТК** — уникальная технологическая компетенция. Запись в БД `utc_records` с полями 1–8 методички.
- **Карточка УТК** — модальное окно просмотра записи (`components/utc-view.tsx`).
- **Альт. применения** — режим «Поиск альтернативных областей применения (новых рынков)» (`components/alt-applications-search.tsx`, API `app/api/utc/[id]/alt-applications`).
- **Конкуренты** — режим «Поиск конкурентов-аналогов» (`components/competitor-search.tsx`, API `app/api/utc/[id]/competitors`).

## §6 R06 — Ссылки на источники в выдаче
- «Поиск конкурентов»: **уже есть** `sourceUrl` у каждой компании (компонент показывает «Источник» с ExternalLink). Требование в этой части — выполнено; проверяем, что ссылка видна.
- «Поиск альтернативных применений»: **добавить**. По каждому варианту из `allVariantsRanked` (или рекомендованным) — через Serper (`searchCompetitors`) искать по описанию варианта, прикреплять 1-2 ссылки (sourceUrl). Не прерывать основной ответ — собирать после первого запроса, по рекомендациям (топ-варианты), лимит ~5 поисков на запрос, таймаут на каждый.
- Данные: расширить `AltApplicationVariant` полем `sources?: { title: string; url: string }[]` (или `sourceUrls?: string[]`).
- UI: в `alt-applications-search.tsx` под вариантом в рейтинге — ссылки «Источник» (ExternalLink).

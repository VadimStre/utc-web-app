## Что проверить (и записать результат в отчёт)

- [ ] Доступен ли `https://dashboard.render.com` (панель) — с этой машины
- [ ] Доступен ли `https://api.render.com/v1` (REST API) — с этой машины (через curl/node fetch; учитывать, что MSYS curl может не поддерживать HTTP/2)
- [ ] Есть ли у пользователя Render-аккаунт (ответ: регистрируется через GitHub)
- [ ] Можно ли автоматизировать создание Postgres и Web Service через API (`Authorization: Bearer <key>`)
- [ ] Если API доступен — какой не хватает: API key из Dashboard → Account Settings

## Критерии приёмки

- [ ] Зафиксирован способ управления Render: API или браузер, с обоснованием
- [ ] Если API — известен способ получить API key (пользователь вводит сам, без чата)

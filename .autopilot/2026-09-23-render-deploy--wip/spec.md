# Спецификация: Деплой УТК на Render.com

## Задача

Проект «База данных УТК» переезжает на Render.com — зарубежный PaaS с GitHub-деплоем, встроенным PostgreSQL и HTTPS из коробки. Прошлые попытки на Timeweb VPS упёрлись в блокировку входящих портов на стороне провайдера; Render решает эту проблему на своей стороне (управляемый HTTPS, публичный домен). Сайт должен быть доступен по HTTPS, с работающей базой данных, сидом админа и корректными секретами — ничего из секретов не должно попасть в чат или репозиторий.

## Решение

Пользователь получает живой сайт `https://<service>.onrender.com`, вход `admin@utc.local`, заполненную демо-данными БД, и все функции системы (ИИ-мастер ввода через Abacus, поиск аналогов, NextAuth-вход) работающими в проде.

## Решения по реализации

- **Способ управления Render**: сначала пробуем автоматизацию через Render REST API (создание Postgres и Web Service, установка env, триггер деплоя) — полностью программный путь; если API недоступен с этой машины (сеть провайдера режет api.render.com) — падаем на ручной путь через браузер.
- **Стек сервиса**: Nixpacks, Build = `npm install && npm run build`, Start = `npm run start`. Эксперименты с выносом схемы в `render.yaml` — только если это ускорит; предпочтителен прямой API.
- **PostgreSQL**: Render managed Postgres, план free (в лимитах бесплатного), region oregon.
- **Миграция/сид**: после деплоя через Shell-команду Render (Preview/Sync): `npx prisma db push && npx tsx scripts/seed-if-empty.ts`; также авто-подготовка БД (см. интерфейсы).
- **Secrets**: имена переменных в .env.example; значения — только в панели Render (env vars зашифрованы), в чат и git не попадают.
- **Проверка**: HTTPS-доступность (curl -I), проверка логина, проверка seeded-данных.

## Границы и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| GitHub repo | исходники, ветка main | https://github.com/VadimStre/utc-web-app | секреты (в .gitignore) |
| Render Web Service | деплой, env, домен | https://<service>.onrender.com | ключи в env |
| Render Postgres | данные | Internal Connection String | пароль БД |
| DB init | схема + сид | `npx prisma db push` + `npx tsx scripts/seed-if-empty.ts` | — |

Швы для тестов: проверка доступности по HTTPS (curl), проверка login endpoint, проверка seeded admin.
